Customer data requests

When a customer asks for the data your store holds about them, Shopify sends a request here. ChatConvert compiles the chat data it stores (conversations and messages tied to that customer's email) so you can hand it over. Download the export below to fulfil the request — Shopify requires this within 30 days.

Data retention

Choose how long ChatConvert keeps raw chat transcripts. Older conversations (and their messages) are deleted automatically each day. This is independent of Shopify's deletion webhooks, which always run regardless of this setting.

Keep forever

How redaction works

ChatConvert also honours Shopify's deletion webhooks automatically: a customer-redact request deletes that customer's conversations and messages, and uninstalling the app (followed by Shopify's shop-redact ~48h later) purges all of your store's ChatConvert data. The only customer information ChatConvert stores is the email a shopper optionally provides in chat.
